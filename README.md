# LLM Compare

Локальное full-stack приложение для параллельного сравнения OpenAI, Anthropic, Google Gemini и OpenAI-совместимых endpoint Timeweb Cloud. Один вопрос отправляется выбранным моделям одновременно; ответы приходят независимыми потоками и сравниваются по скорости, токенам, стоимости и качеству.

## Интерфейсы

- `/` — классический интерфейс: чаты, модели, аналитика, оценки ответов;
- `/x/` — новый интерфейс сравнения по макету: тёмная тема, колонки моделей, закреплённые шапки, история и профиль в сайдбаре. Хостится на https://llm.stud-life.com/x/.

### Возможности `/x/` (задание CodeX)

Минимальные требования:

- клиент + сервер; запросы к моделям отправляет только сервер (`/api/generate`);
- сервер отдаёт список моделей; модели добавляются колонкой с «+» справа, открывается список с поиском, в сравнении от 2 до 4 моделей;
- вопрос из формы внизу уходит во все модели параллельно;
- ответы в колонках рядом: в шапке колонки название, провайдер и кнопка удаления; шапка закреплена при скролле; под ответом время в секундах;
- Markdown рендерится: заголовки, списки, таблицы, блоки кода (с кнопкой Copy);
- ошибка или таймаут одной модели не ломает остальные: в её колонке сообщение и кнопка «Повторить».

Расширенные требования:

1. **Стримы** — ответы приходят стримами и печатаются во всех колонках одновременно с мигающим курсором; кнопка «Остановить» прерывает генерацию у всех моделей;
2. **Метрики** — время до первого токена, общее время, токены на входе/выходе и стоимость; самая быстрая и самая дешёвая модель подсвечиваются бейджами;
3. **Thinking** — пока модель не выдала первый токен, показывается анимированная пометка «Thinking»; после ответа — раскрываемая строка «Думала N секунд»;
4. **Форма ответа** — закреплена внизу с градиентом поверх текста, авторесайз поля, отправка по Enter (Shift+Enter — новая строка), диалог продолжается с сохранением контекста каждой модели;
5. **Markdown через AST** — рендеринг через react-markdown + remark-gfm (парсинг строки в mdast-дерево и отрисовка по блокам).

Общие требования:

- без готовых UI-библиотек компонентов (React + собственные стили);
- мобильная адаптация: на узком экране колонки превращаются во вкладки;
- история сравнений и профиль (общие с классическим интерфейсом), ссылка-копирование чата, ссылка на классический интерфейс;
- токены провайдеров хранятся в `.env` / в зашифрованном виде на сервере и не попадают ни в репозиторий, ни в клиент.

### Демо-режим без регистрации

По умолчанию список демо-моделей пуст: гость `/x/` добавляет свои модели вручную через «Своя модель» в списке (ключ хранится только в localStorage его браузера). Токен для тестирования выдаётся в чате задания.

При желании сервер может отдавать встроенные демо-модели (`GET /api/demo/models`), доступные всем посетителям `/x/` — ключ провайдера хранится только на сервере в `.env`:

```bash
DEMO_BASE_URL=https://api.timeweb.ai/v1
DEMO_API_KEY=ключ_провайдера
DEMO_MODELS=GPT-6-Luna|OpenAI|openai/gpt-6-luna,Claude Haiku 5.5|Anthropic|anthropic/claude-haiku-5-5
```

Формат `DEMO_MODELS` — записи `Название|Провайдер|model_id` через запятую. На демо-модели действует лимит 30 генераций в час с одного IP. Гостевые чаты дополнительно сохраняются на сервере (`POST /api/shared`), поэтому скопированная ссылка открывает историю в режиме «только чтение» у любого, кому её отправили.

## Возможности

- потоковые ответы 1–10 моделей, независимые ошибки, тайм-ауты и отмена;
- многоходовые чаты с отдельным контекстом каждой модели;
- регистрация и вход, изоляция пользовательских данных;
- гостевой режим: история в `localStorage`, ключи только в памяти вкладки;
- зашифрованные API-ключи аккаунтов (AES-256-GCM);
- пользовательские оценки, выбор победителя и ручная ИИ-оценка;
- аналитика скорости, токенов, расходов и качества;
- адаптивный русскоязычный интерфейс.

Для Timeweb Cloud выберите соответствующего провайдера и вставьте Base URL AI Gateway (`https://api.timeweb.ai/v1`) либо полную ссылку AI-агента. Сервер принимает только HTTPS endpoint на доменах Timeweb и автоматически добавляет `/chat/completions`, когда требуется.

## Требования

- Node.js 22.5+ (используется встроенный `node:sqlite`);
- действующий API-ключ хотя бы одного поддерживаемого провайдера.

## Локальный запуск

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Скопируйте `.env.example` в `.env` и задайте длинный случайный `ENCRYPTION_KEY`:

   ```bash
   cp .env.example .env
   ```

   В PowerShell: `Copy-Item .env.example .env`.

3. Запустите клиент и API:

   ```bash
   npm run dev
   ```

4. Откройте `http://localhost:5173`, перейдите в «Модели», добавьте реальный ключ и нажмите «Проверить подключение».

SQLite создаётся автоматически в `data/llm-compare.sqlite`.

## Проверки и production-сборка

```bash
npm test       # unit-тесты расчёта стоимости и оценки токенов
npm run check  # проверка TypeScript
npm run build  # production-сборка интерфейса
NODE_ENV=production npm start
```

Собранный интерфейс обслуживается Express из `dist/client`. По умолчанию API слушает порт `3001`.

## Безопасность

Не коммитьте `.env`, базу данных и ключи. Ключи аккаунтов шифруются с помощью `ENCRYPTION_KEY`; при его смене существующие ключи невозможно расшифровать. В production запускайте приложение только через HTTPS, используйте уникальный секрет и ограничьте доступ к файлу SQLite. Запросы ИИ-оценщику отправляются лишь после явного подтверждения пользователя.

## Production с Docker

Production-конфигурация собирает приложение в контейнере и публикует API только на loopback-интерфейсе:

```bash
cp .env.example .env
# Задайте уникальный ENCRYPTION_KEY и APP_ORIGIN.
docker compose -f compose.production.yml up -d --build
curl http://127.0.0.1:3101/api/health
```

Пример HTTP reverse proxy находится в `deploy/nginx-http.conf`, HTTPS-вариант — в `deploy/nginx-https.conf`. Последний ожидает сертификат Let’s Encrypt для `llm.stud-life.com`. Каталог `data/` должен находиться на постоянном диске и включаться в резервные копии. Не меняйте `ENCRYPTION_KEY` после появления сохранённых конфигураций моделей.

## Структура

- `src/` — React-интерфейс, страницы чата, моделей и аналитики;
- `server/` — Express API, SQLite, авторизация, шифрование и адаптеры провайдеров;
- `data/` — локальная база (создаётся при запуске и игнорируется Git).
